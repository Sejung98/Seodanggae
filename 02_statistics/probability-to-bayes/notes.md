# 확률에서 베이지안까지

공부한 날짜:
참고 자료: 노트북마다 끝의 `## 출처` 절. 같이 볼 공개 강의·교재(Harvard Stat 110, Statistical Rethinking, Think Bayes 2 등)의 회차는 각 노트북 머리에 적습니다.

## 왜 공부했나

확률 공부를 오래 쉬어서 기초(분포가 무엇인지, 분포끼리 어떻게 비교하는지)부터 다시 하고, 시퀀싱 데이터 분석에서 많이 쓰는 베이지안 방법을 이해하려고.
