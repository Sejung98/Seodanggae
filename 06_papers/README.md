## Adding a paper

1. Make `06_papers/year-firstauthor-topic/` and write `notes.md`.
2. Add a row under every theme it belongs to.

Notes are my own summary and critique. Figures are linked to the original article, not copied.

정리 글은 내 요약과 비평이고, 그림은 복사하지 않고 원문 링크로 둡니다.
